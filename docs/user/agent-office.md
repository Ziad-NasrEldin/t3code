# Agent office

Open **Office** from the sidebar or command palette to view an environment's projects and threads as a Signal Crew office. The environment selector keeps machines separate and shows input requests elsewhere. Disconnected offices show unknown activity, keeping their last known occupants.

Select an agent or find it in the directory to open its chat, settle it with the usual Undo, or pause its current turn. **Pause chat stops the turn**; sending another message continues the conversation. Native provider children open their owning parent's chat because they cannot receive messages directly. Chat keeps the normal composer and actionable requests, while its transcript shows user messages and completed final responses.

Completed main agents visit the shared lobby. Completed children stay on their project's floor until explicit closure is known. Some providers and older histories do not expose closure; those children remain visible. Visits never send prompts or delay real work.

Rooms keep their sites as projects grow into outer rings. The directory reaches every occupant; crowded projects and the shared lobby use additional decks. Select an agent to focus its current deck. Music starts muted and is opt-in. Office preferences also control effects, text excerpts, graphics load and reduced motion. If graphics fail, the directory and ordinary T3 chat remain available.
